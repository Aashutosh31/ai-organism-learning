# Contributing / Working Rules

This is primarily a personal public learning repository.

Please keep contributions educational, focused, reproducible, and free of secrets or private project details.

## For my own work

Prefer the cycle:

1. Learn a concept.
2. Explain it in your own words.
3. Implement it.
4. Build or extend a small project.
5. Record what worked, what failed, and what to learn next.

Keep unrelated experiments separate and use focused commits.
