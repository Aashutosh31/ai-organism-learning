# AI Systems Learning

A public learning repository containing notes, implementations, experiments, and small projects from my study of AI, machine learning, deep learning, language models, agents, systems, and related topics.

This repository is intentionally focused on **what I am learning and building while learning it**. It is not intended to document every downstream project or research direction.

## What lives here

- Concept notes and mental models
- From-scratch implementations
- Coding exercises
- Small experiments
- Mini-projects
- Research-paper notes
- Useful resources
- Learning journal entries

## Working principle

Learn → understand → implement → experiment → document.

Notes should explain ideas in my own words rather than copy tutorials. Code and experiments are the primary evidence of understanding.

## Repository boundary

This is a public learning repository. Private projects, credentials, local infrastructure details, unreleased research, secrets, and implementation details of private systems do not belong here.
